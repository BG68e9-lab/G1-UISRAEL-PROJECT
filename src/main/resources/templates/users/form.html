Información sobre Usuarios
Autenticación Local
  • Usuario y contraseña administrados localmente
  • Contraseña mínimo 8 caracteres
  • Debe incluir letras y números
  • Se puede cambiar desde el perfil
Single Sign-On (SSO)
  • Autenticación mediante proveedor externo
  • No requiere contraseña local
  • Requiere configuración de proveedor
  • ID único debe coincidir con SSO
Consideraciones de Seguridad

• Los emails deben ser únicos en el sistema
• Los usuarios inactivos no pueden iniciar sesión
• Los roles se asignan por separado después de crear el usuario
• Solo administradores pueden crear y modificar usuarios
